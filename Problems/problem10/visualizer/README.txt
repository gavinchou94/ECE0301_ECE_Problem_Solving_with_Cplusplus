Problem 10 circuit visualizer (provided, optional, not graded)

1. In VS Code, set the build target to "visualize" and run "CMake: Build".
2. This writes circuit_trace.txt in your Problem 10 folder (next to CMakeLists.txt).
3. Load that file in the circuit visualizer embedded in the Problem 10 statement
   on Canvas. It draws the circuits your code builds and lists what to fix.

A stage whose classes do not compile yet is reported as "does not compile yet";
the other stages are still drawn.

Do not edit the files in this folder. They are not part of your submission.
